# Mika's Multiplication Magic 🦫✨

An interactive multiplication learning game designed for an 8-year-old Hebrew speaker, featuring a capybara collection system to make math practice fun and engaging.

## Features
- **Touch-optimized interface** - Custom number pad designed for iPad Pro
- **Capybara rewards** - Collect real capybara images every 3 correct answers
- **Milestone celebrations** - Special capybara photos appear every 10 collected
- **Hebrew interface** - Fully localized with feminine conjugation
- **Range 1-10** - Focuses on essential multiplication tables
- **Progress tracking** - Real-time scoring with streak counter
- **Responsive design** - Optimized for iPad Pro (11" & 12.9")

## Tech Stack
Pure HTML/CSS/JavaScript • Unsplash API for capybara images • No dependencies

Perfect for young learners who love capybaras and need motivation to practice multiplication! 🎯
