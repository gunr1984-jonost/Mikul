# Mika's Multiplication Game

A Hebrew multiplication learning game for 8-year-olds featuring capybara collection rewards.

## Features

- Touch-optimized number pad for iPad
- Hebrew interface with feminine conjugation
- Multiplication practice (1-10 tables)
- Collect capybara images (3 correct answers = 1 capybara)
- Exchange 10 capybaras for reward videos
- 28 unique capybara images
- 8 reward videos (persistent collection)
- Game completion when all videos collected

## File Structure

```
mika-multiplication/
├── index.html
└── resources/
    ├── pics/          (28 capybara images)
    └── videos/        (8 reward videos)
```

## How It Works

1. Answer multiplication questions correctly
2. Every 3 correct answers = 1 capybara image
3. Collect 10 capybaras → exchange for 1 video
4. Videos stay in collection permanently
5. Collect all 8 videos to complete the game

## Tech Stack

- Pure HTML/CSS/JavaScript
- No dependencies
- No build process
- Single file application

## Setup

1. Upload all files to GitHub
2. Enable GitHub Pages (Settings → Pages → main branch)
3. Open the provided URL on iPad
4. Add to home screen for app-like experience

## Requirements

- Modern web browser
- Touch device recommended (iPad)
- Internet connection for initial load

## Game Rules

- No keyboard needed - touch-optimized interface
- Hebrew right-to-left text
- Automatic progress tracking
- No repeating images/videos until all shown
- Instructions appear on first launch
